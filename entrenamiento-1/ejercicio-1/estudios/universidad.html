Competencias adquiridas

La carrera de Desarrollo Web permite adquirir conocimientos y habilidades para diseñar, desarrollar y mantener sitios y aplicaciones web. Entre las competencias se encuentran el manejo de HTML y CSS, programación con JavaScript, desarrollo de interfaces, bases de datos y programación orientada a objetos. También se desarrollan habilidades para resolver problemas, trabajar en equipo, utilizar herramientas de desarrollo y crear soluciones web funcionales y accesibles.
