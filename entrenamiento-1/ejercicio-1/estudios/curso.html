Curso de HTML y CSS

Competencias adquiridas

El curso de HTML y CSS permite adquirir conocimientos para crear y diseñar páginas web. Se aprende a estructurar el contenido utilizando HTML y a darle estilo mediante CSS, trabajando con textos, imágenes, enlaces, listas, colores, tamaños y distribución de los elementos. También se desarrollan habilidades para crear diseños organizados, atractivos y adaptables a diferentes tamaños de pantalla.
