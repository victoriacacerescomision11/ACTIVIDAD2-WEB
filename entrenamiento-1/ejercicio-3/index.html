pizza

Volver al índice

Para preparar una pizza, primero se realiza la masa mezclando harina, agua, levadura, sal y un poco de aceite. Se amasa hasta obtener una preparación suave y se deja reposar para que aumente su tamaño. Luego se estira la masa, se coloca salsa de tomate y se agrega queso junto con los ingredientes elegidos. Finalmente, se lleva al horno hasta que la masa esté dorada y el queso completamente derretido.

Hamburguesa

Volver al índice

Para preparar una hamburguesa, primero se condimenta la carne y se forman las hamburguesas con el tamaño deseado. Luego se cocinan en una sartén, plancha o parrilla hasta que estén bien cocidas. Mientras tanto, se prepara el pan y se pueden cortar ingredientes como tomate, lechuga y cebolla. Finalmente, se coloca la carne dentro del pan junto con queso, verduras y los condimentos elegidos.

Pasta

Volver al índice

Para preparar pasta, primero se coloca agua en una olla y se agrega un poco de sal. Cuando el agua comienza a hervir, se incorporan los fideos y se cocinan durante el tiempo indicado en el paquete. Mientras se cocina la pasta, se puede preparar una salsa de tomate, crema o la que se prefiera. Una vez lista, se escurre la pasta, se mezcla con la salsa y se sirve caliente.

Ensalada

Volver al índice

Para preparar una ensalada, primero se deben lavar correctamente todas las verduras. Se pueden utilizar ingredientes como lechuga, tomate, zanahoria, cebolla y otros vegetales según el gusto. Luego se cortan los ingredientes en trozos pequeños y se colocan en un recipiente. Finalmente, se mezclan y se condimentan con sal, aceite, limón o el aderezo elegido.

Empanada

Volver al índice

Para preparar empanadas, primero se prepara el relleno utilizando ingredientes como carne, pollo, verduras, queso u otras opciones. Una vez listo, se coloca una porción del relleno en el centro de una tapa de empanada. Luego se dobla la masa por la mitad y se cierran los bordes realizando un repulgue para evitar que el relleno se salga. Finalmente, las empanadas se cocinan al horno o fritas hasta que la masa quede dorada.
